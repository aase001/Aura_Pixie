# Aura Pixie
> 一款桌面可配置软件/快捷指令/代码启动器
常驻透明呼吸圆球，悬停展开扇形菜单，一键执行你的常用指令,轻量、静默、单文件分发。
## 简介
Aura Pixie 是一个驻留在桌面任意位置的呼吸光效圆球小助手：
- 平时是一个透明呼吸的小球，不遮挡视线、不进任务栏；
- 鼠标悬停在球上约 300ms，圆环扇形菜单自动展开，展示你设置的功能模块（2-9个）；
- 点击扇区立即执行对应指令（打开应用、运行脚本、执行命令、甚至一键发射核武器），执行后自动收起复位；
- 球体可以拖动、贴边吸附，位置自动记忆，下次启动原样恢复。
它适合把高频操作收拢到一个"触手可及"的入口：重点是它好看又好用。
## 功能特性
- 常驻呼吸球体：透明无边框、可置顶（可选）、不进任务栏；无描边、光晕虚化过渡
- 悬停展开动态扇形：鼠标累计悬停 300ms 展开，等分数 = 激活功能数（2~9，超出取前 9）
- 点击执行 + 闪光反馈：成功白闪 220ms / 失败红闪 420ms，静默执行、自动复位
- 三种指令格式：`python代码` / `cmd命令` / `powershell 5.1~7.x`，支持多行编写，一切静默无黑窗
- 指令高级编辑窗：右键指令单元格 →「高级编辑…」，独立大窗口编写指令，内置「测试 / 保存 / 取消」——测试真实运行并展示输出，保存仅校验语法（⚠ 测试会真实执行指令，窗口内有醒目警示）
- 球体拖动 + 屏幕吸附：弹簧非线性跟随，外缘距屏幕边缘 ≤200px 自动吸附，越界红虚线闪烁回弹
- 动效休眠：无交互到达设定秒数 → 呼吸暂停、透明度降至休眠值，并随系统深浅色顺色保持可见；点击唤起
- 球体自定义光效：呼吸色、呼吸倍率（0.1x~3x）、休眠倒计时（10~600s）、总体/休眠透明度
- 单实例 + 定位：全局仅一个实例；二次启动弹「本球在此」，可一键「在哪儿？」让运行中的球体红框闪烁定位
- 开机自启（可选）：默认不勾选，勾选则写注册表
- 位置记忆：关闭时保存球心坐标，下次按记录打开；无记录默认屏幕右侧中间贴边
- 统一配置：配置主位置 `%LOCALAPPDATA%\Aura_Pixie\setting.yaml`
- 配置导入/导出：一键备份到任意文件夹、导入合并（内容合法性校验）
- 单文件分发：图标内嵌，无需安装依赖
## 使用说明
### 球体交互
|     |     |
| --- | --- |
| 操作 | 行为 |
| 悬停（约 300ms） | 展开扇形菜单，等分为激活功能数 |
| 悬停移动 | 高亮跟随光标所在扇区 |
| 单击扇区 | 闪光反馈 → 静默执行指令 → 收起复位 |
| 按住拖动 | 移动球体；外缘距屏边 ≤200px 松手自动吸附 |
| 右键球体 | 打开/置前设置窗 |
| 点击休眠球 | 唤醒并恢复正常透明度 |
### 设置界面
- 激活：勾选后该功能计入扇形等分数（2~9）；
- 功能：扇形上显示的名称（≤6 汉字 / 12 字母）；
- 指令：双击 = 行内多行编辑；右键 → 高级编辑… = 独立大窗口（推荐编写复杂/多行指令）；
- 拖动整行可调整功能顺序（保存后即时生效）；
- 底部「保持球体置顶」「开机自启动」开关勾选即时生效；
- 「动效」子窗口可调颜色/呼吸倍率/休眠/透明度；
- 「导入/导出配置」支持备份与恢复。
### 指令格式
详情请见设置 - 帮助窗口，以下仅作展示
指令默认按 Python 处理；以格式名前缀开头可切换执行环境：
```
cmd: start notepad                     # CMD：打开记事本
ps: Start-Process notepad              # PowerShell 5.1
pwsh: Write-Host "hi"                  # PowerShell 7（无则回退 5.1）
py: import subprocess; subprocess.Popen(['notepad.exe'])   # Python（默认）
```
多行写法：第一行写 `格式名:`，指令内容从第二行开始（也可以与格式名同行）。
- `cmd` 多行会逐行依次执行，自动用 `&` 连接，每行独立、不要缩进；
- `ps/pwsh` 多行按换行连接执行，块内语句保持缩进、顶层顶格；
- `py` 多行即完整 Python 程序，保留换行与缩进，块内 4 空格、顶层顶格。
所有指令静默执行（`CREATE_NO_WINDOW`，不会弹黑色控制台窗口）；程序只负责启动指令，不等待运行结束，UI 不卡顿。
### 指令高级编辑窗
在设置窗「指令」列单元格上右键 → 高级编辑…：
|     |     |
| --- | --- |
| 按钮 | 行为 |
| 测试 | 按扇区点击完全一致的逻辑真实执行当前指令（可能启动程序、修改文件或联网，窗口内有醒目警示），执行输出/退出码/错误信息实时显示在窗口内结果区；超时（15s）停止轮询，进程后台自行结束 |
| 保存 | 仅校验格式/语法是否合法，不执行；非法弹窗「代码异常请查证」并留在编辑窗，合法写回单元格 |
| 取消 | 不做任何更改，直接返回设置界面 |
## 配置说明
配置文件：`%LOCALAPPDATA%\Aura_Pixie\setting.yaml`（四个功能块）：
```
functions:                          # 功能扇区（顺序 = 扇形顺序）
  - name: "开记事本"                # ≤6 汉字 / 12 字母
    code: "cmd: start notepad"      # 前缀：无/py:（默认）/ cmd: / ps: / pwsh:
    active: true                    # 勾选计扇形
aura:                               # 光效
  color_mid: "#FFFFFF"              # 中间彩色（十六进制）
  aura_scale: 1.0                   # 呼吸倍率 0.1~3.0
  idle_sec: 60                      # 休眠倒计时 10~600 秒
  opacity: 100                      # 总体透明度 10~100%
  sleep_opacity: 10                 # 休眠透明度 1~20%（>总体则存 10）
autostart:
  enabled: false                    # 开机自启动（写 HKCU Run）
window:
  always_on_top: false              # 保持置顶
  pos_x: null                       # 球心记忆位置（关闭时自动写）
  pos_y: null
```
配置迁移：本程序支持一键迁移同款配置，避免复制代码出错影响功能使用

- Python 3.12（项目自带 `.venv`）
- PySide6 6.12（Qt6，LGPL）
- pyyaml、Nuitka 4.3.1（打包用）

## 常见问题
Q：指令点击后没反应？
A：先确认指令格式无误（参考上文「指令格式」）；py 语法错误 / 指令为空的条目不会执行，扇区闪红光提示。可以在设置窗右键 → 高级编辑 →「测试」直接查看真实输出与错误信息。
Q：配置在哪里？换电脑怎么迁移？
A：配置位于 `%LOCALAPPDATA%\Aura_Pixie\setting.yaml`。设置窗「导入/导出配置」→ 导出可备份到任意文件夹（`setting.yaml.bak`），新机器上「导入」即可迁移；或直接复制该 yaml 文件。
Q：怎么开机自启动？
A：设置窗勾选「开机自启动」即可（写 HKCU Run 键，启动自检自动重建）。
Q：球体不见了？
A：程序单实例运行，再启动一次会弹「本球在此」→ 点「在哪儿？」即可让运行中的球体红框闪烁定位。
